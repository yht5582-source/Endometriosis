# 子宮內膜異位症臨床學習站

依 ESHRE 2022 與 NICE NG73（2024-11-11 更新）整理的繁體中文互動教學：診療情境分流、14 個示範病例、綜合測驗 20 題（基礎 10＋高階 10）、住院醫師與進階各 10 題、診斷與治療心智圖。

網站：<https://yht5582-source.github.io/Endometriosis/>

本頁供教學使用，不能取代臨床診斷與個別化治療。國際指引（ESHRE／NICE）與台灣健保給付規定分開標示。

本地測試：`node --test tests/*.test.mjs`（26 項）

## v1.4（2026-11-01）教學內容
- 示範病例增加 8 個（共 14 個）：藥物禁忌、影像陰性、輸尿管、急症、健保對照、EFI、停經後、胸腔病灶；可帶入分流或健保工具
- 綜合測驗 20 題：基礎 10＋高階 10，四選一，A–D 各 5 題，每題附依據；原有 20 題保留

- 內容放在 `teach-content.mjs`，病例結果由 `tests/teach.test.mjs` 與分流、健保引擎交叉驗證
