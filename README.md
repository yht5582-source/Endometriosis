# 子宮內膜異位症臨床學習站

依 ESHRE 2022 與 NICE NG73（2024-11-11 更新）整理的繁體中文互動教學：診療情境分流、6 個示範病例、住院醫師與進階各 10 題考題。

網站：<https://yht5582-source.github.io/Endometriosis/>

本頁供教學使用，不能取代臨床診斷與個別化治療。尚未整合台灣健保給付規範。

本地測試：`node --test tests/clinical.test.mjs`（15 項）
